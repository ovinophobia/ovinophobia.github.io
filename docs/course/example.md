# 示例课程：如何整理一篇学习笔记

> 日期：2026-11-22 · 分类：学习方法

这是一篇示例文章。以后写新文章时，可以复制这个文件，再替换标题和正文。

## 学习目标

读完这篇文章，你将了解如何用 Markdown 写标题、列表、链接和代码。

## 课程内容

### 1. 写清楚核心概念

用自己的话解释今天学到的知识。段落之间空一行，就能分成不同的段落。

可以用 **加粗** 标记重点，用 *斜体* 添加补充说明。

### 2. 用列表整理步骤

1. 阅读课程材料。
2. 整理重要知识点。
3. 完成一个小练习。
4. 回顾并写下自己的理解。

### 3. 记录示例代码

代码放在三个反引号之间，后面写上语言名称。例如：

```python
print("你好，欢迎来到 ovino！")
```

!!! tip "写作小提示"
    不必一次写得很完整。先记下今天学到的一点内容，再慢慢补充。

## 课后练习

- 用一句话总结今天的收获。
- 写出一个还没有弄懂的问题。
- 试着把知识应用到自己的小项目中。

## 总结

好的学习笔记可以包含：学习目标、核心内容、示例、练习和总结。
