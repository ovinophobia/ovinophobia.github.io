# 习概

- **任课教师：** 楼俊超
- **学分：** 3.0
- **课程类别：** 通识课程 思政
- **学期：** 2025-2026秋冬

## 课程总结与建议

之前老师因为一些原因被骂上过十大，抛开这个，上课和给分其实还是不错的。

小组任务包括一次实践调研，一个微电影，两次课堂展示（会给出主题），这些应该是习概课程组统一的。由于人数众多，一个组有12个人，所以实际上分到的活不算很多，而且运气比较好遇到了一个好组长，整体来说不折磨。说是调研实际我们只是派了3个还是4个去一个村子，拍拍照，甚至也没有访谈，然后找资料结合拍的“风景”做了个AI念稿的视频。草台班子这一块。

老师的平时分会在平时统计一个“活跃度”，上课回答问题/交流+1，参加个人梦想展示+1，交一份“人生三问”的文章+3，后两项每人限一次。我只交了人生三问+3，最后参考活跃度给一个平时分分数。如果你只追求4.2/4.5，交个人生三问这种完全够了，其实最后的统计大部分同学（60%-70%）都在3-5分，个别会有每节课都回答问题加到十几分的，我感觉完全没必要。从结果来看，哪怕活跃度没那么高，老师给分也不差的。
