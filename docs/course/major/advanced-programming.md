# 高级程序设计

- **任课教师：** 耿晨歌
- **学分：** 3.0
- **课程类别：** 专业课程必修
- **学期：** 2025-2026秋冬

## 课程总结与建议

下一届这个就不是必修课了。今年的作业砍到只剩代码计数的大作业网页设计了，在ai帮助下很容易完成。期末考占50，课程学习内容没变，ppt版搜就有。课程的核心就是“面向对象的编程”，以往还要考java的语法，今年考试周一周前耿哥说不考语言特性（java/python都是考试合法的），只有简答题和编程大题。考前大家都在哀嚎，我高中选了技术所以会一点python，java只是在复习时候看了一下菜鸟教程，粗略学了一下。备考就完全没看代码，主要关注正则表达式、设计模式这些。
从考试和给分来看，确实算是符合“面向对象编程”这个目标。我直接是python，java语法混着乱写，各种错误不计其数，但是写了很多自然语言的说明，耿哥改卷的时候应该也是弱化了代码的分数，更关注思路。出分后我说耿哥放了一片海。耿老师的恩情还不完\o/\o/\o/

考试比较好的思路应该是：

画流程图/继承结构图/步骤图等，配以文字，说明你想干什么，每一步实现了什么功能-->给出关键代码，比如你的正则表达式是什么，要初始化哪些变量，分别记录什么参数，要创建哪些类-->具体功能代码（这步其实最没用，本身试卷空间有限，老师也没办法一行行细致的检查代码，把上面两步做好，我觉得就能拿到不错的分数了）

虽然耿老师很好，但是这个课程确实有问题，面向对象编程既然是编程，就必然要写代码，但是java和python都不是必修，而大一学的C从编程语言的角度和java/python这类更高级的语言差别很大，语法什么的很难迁移。但是完全抛弃代码这个地基去理解“面向对象编程”这一理念又是不现实的，就造成很大矛盾。同学们很可能是既没学会语法，对于“面向对象编程”也没有很好的了解。（耿老师的网络技术选修课停开了，我想可能也是这个原因，大家想学，但又很难迈入这个门槛）不过下一届就不是必修了，也不知道耿老师对课程还会不会有改动
