# 生物医学传感与检测

- **任课教师：** 唐志峰/张芬妮/刘清君
- **学分：** 3.0
- **课程类别：** 专业课程必修
- **学期：** 2025-2026春夏

## 课程总结与建议

教学班的差异应该不大，而且反正是半开卷，理论课不听的话又有什么区别呢

今年的改革在于完全取消了英文授课，从上课，ppt，考试全部都是中文。以及半开卷考试。

选课的话实验课和教务网上的时间是不一样的，在开学后会重新排时间，今年有周三晚上，周四早八早十下午一共四个时间段，然后所有教学班全部混在一起，自己二人组队挑时间，周四早十和下午会比较热门。实验时间也不是单双周，而是春5开始每周连续做8次。

唐老师的物理部分会喊人回答问题，而且个人感觉一次没到被记下来之后有不小概率被反复点，化学和生物部分没有点名。

物理部分会有几次作业，化学一次，生物没有。实验都比较简单，大部分一个小时多一点就做完了，实验报告会有老师自己的模板，心得那块虽然说没有什么要求，但最好还是多写一点，说是可以从“传感器原理”展开，然后我就多复制一点ppt上的图或者文字描述语言写上去了。

另外，教材其实完全不需要，考试完全是根据ppt来的，我教材一共就翻了两三次之后再也没打开了。我始终建议，半开卷资料的A4要打印，不要手抄，知识携带量不是一个级别的，然后把ppt上的内容想办法塞进去就好了，记得尽量多放图，从今年的试卷来看，很多都需要你画出测量装置的原理图或者结构图之类的，至少要做到大部分传感器的原理都有个印象。

放进资料里的每个传感器的知识要包括**原理+结构/测量电路+至少一个应用**。98上已经有不少半开卷资料了，不过还是提醒大家，任何资料都会有疏漏，而且这么大体量的资料一定要自己浏览过，结合ppt校对一遍，看一遍。光靠考场上两小时当场找是很危险的。
