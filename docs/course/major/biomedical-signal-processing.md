# 生物医学信号处理

- **任课教师：** 王贤迪
- **学分：** 3.0
- **课程类别：** 专业课程必修
- **学期：** 2025-2026秋冬

## 课程总结与建议

生仪为数不多能学到东西的课。除理论课外有实验、project。

我在这里对wxd和zj两位老师的区别做一些说明，王老师这学期是第一次独立开课，确实对于课程整体进度、知识细节把控不如郑老师，但是王老师的ppt内容非常精炼，重点、层次分明，上课对于大家不懂的地方也会耐心一遍遍讲，相信以后会越讲越好的！

（另外，听说zj班Z变换的内容不是郑老师讲的，我本人对于这种中途换讲向来是比较反感的，像成像这种各部分内容不相关倒是无所谓，信号这个课前后知识的联系还是比较强的，我不喜欢中途某一部分换老师讲。）

对于考试周复习，如果你是zj班的，记得问wxd班的同学要一份上课ppt；如果你是wxd班的，记得去智云上看一遍zj老师的复习课。

考试的话回归作业很重要！！！能独立完成作业题，考试就不会有大问题了。考前看到很多同学都在记各种变换对和公式，很痛苦，我个人感觉方向偏了，我只记了时移和频移两个公式，然后是方波三角波三角函数的变换对，其他复杂的变换公式都没记，拉普拉斯变换一点没看（复变已经考察过了，没必要在信号再考一遍）。我承认有赌的成分，但结果确实就是只考了基本的变换。

给分是不错的，只是project答辩时候，刁难的问题都是王老师提的
