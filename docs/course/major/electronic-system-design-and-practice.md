## 课程总结与建议

[原帖](https://www.cc98.org/topic/6575723){ target="_blank" rel="noopener noreferrer" }

- 关于分数

    虽然说这个课的实验确实一言难尽，但是整体的给分似乎还是可以的，我自己虽然比较低，但是我知道是自己的原因，具体就不细说了。记得是45p实验，45p考试，10p点名。之前问了助教，实验部分只要验收通过，报告按时交且没有明显划水这部分基本就给满了，最后看来报告这部分应该都是给的比较高的。点名部分lxs的班时只要在点名表上勾5次就给满了。考试的话根据历年卷和最后一节课画的重点拟合一下基本也就大差不差。

    虽然做实验的过程比较痛苦，但是最终成绩不需要太过担心。

- 关于理论课

    一共十章内容，每年的ppt应该也都是一样的。误差分析，模电设计，数电设计，计算机辅助设计（不考），低频电路设计，高频电路设计，数字逻辑电路设计，HDL，高速电路设计，最后一章是老师自己的项目分享，两个班不一样但是不考。

    这部分的建议和往年的经验贴一样，理论课没有什么听的必要，按照要求保证点名部分分数拿到就行，毕竟大三下很忙，建议花时间再更有用的事情上。不过lxs的最后一节复习课强烈建议听一下，无论你是哪个班，真的很有用，然后考前过一遍ppt，拟合一下历年卷，再看看前辈们的复习资料也就差不多了。老师改卷还是比较捞的。

- 为什么这节课被广为吐槽

    生仪学院的网红课程之一，版搜能找到很多经验贴和各种吐槽。我个人感觉原因主要在这几个点：

    1. 理论课教学内容意义不明且落后。

        有人说教学与实验分离，老生常谈了，我只能说现在的本科课程能做到教学和实验不分离的才是少数，但个人认为这不是最关键的点，重点在于理论课的内容与其他课程大量重复，模电和数电都有对应的基础课覆盖，HDL和误差处理部分有专门的专业课，所以这门课的理论课就完全意义不明，要么干脆把理论课和考试砍了，变成纯实验课程。要么就把理论课的内容改成更加有意义的东西而不是炒冷饭。

    2. 实验课内容设置不合理。

        首先就是与仪器大二短学期内容明显重复。然后就是明明说是电子系统设计，但是实际上实验一的电路板已经画好了，硬件都是确定的，最后演变成只剩下焊板子和写代码，那这个“设计”体现在哪里呢。实验二是测温，脉搏，心电三选一，电路图都给出了，相比实验一只是多了一步自己画原理图和pcb，依然是那个问题，“设计”体现在哪里。虽然也说了实验二可以自选题目，但是在大三下这样一个时间节点，忙的要死哪有时间，而且这个所谓自选真就是完全自己搞了，一旦遇到什么阻碍老师大概率是什么都帮不了你的，只能提提意见。

        所以就很尴尬，你想自己做点东西一没时间二没相应的指导，所以最后只能老老实实做个测温交差。

- 关于实验课的种种
    
    - 实验一

        有兴趣的可以看我[这个帖子](https://www.cc98.org/topic/6457984){ target="_blank" rel="noopener noreferrer" }，大致记录了春学期阶段每周大概干了什么，基本上是2-3周焊板子，然后就是写代码调代码，验收。遇到的一些小问题也有所记录。

        1. 尽量用口袋实验室给板子上电，因为有+-5V，直流电源只有正点压，这会导致358很烫，但不会坏。而且这个可以防止你一不小心改了直流电源的输出电压导致板子烧坏

        2. 三根正负电源接地线没什么用，因为是鳄鱼夹的头，是用来接直流电源的，但是用口袋实验室上电的话用的是另一侧的排针，不过为了验收还是要焊一下

        3. 由于很多排针挨得很近，建议用杜邦线引出来再接信号发生器或示波器，不要直接把鳄鱼夹夹到排针上去

        4. 实验讲义上有用于测试硬件功能的demo代码，可以用来测试led和按钮，但是那个测试adda的是错的，不要用

        5. 相信祖传代码，相信自己的焊接能力，怀疑一切实验设备。焊完并且初步测试完后先烧一个祖传测试一下，如果没波形，看看是不是ch1和ch2接错，是不是两个鳄鱼夹的头碰到一起了，已经可能示波器、信号发生器、信号线是坏的。

        6. 记得代码归代码，验收归验收，交上去报告里的代码不等于实际验收时烧录的代码

        7. 虽然如上一条所说，你可以烧一份好的代码（比如祖传）验收，再交一份实际并不能跑的代码在报告里，但是验收时会有各种提问，或者让你当场改代码的情况，所以务必先熟悉祖传代码，每一部分在干嘛，原理是什么，再去验收，今年验收基本都是yyw自己看的，所以一定要自己搞懂

        8. 我们验收时问的一些问题

            1. 我们上来先主动解释了采样率，问了一个定时器怎么设置的250（回答：每次中断溢出的时候赋初值，从6开始数到256）

            2. 展示翻转频率，他说我们这个1k不是很稳定（原因说是可能是祖传在每次中断里加入了很多计算，我们改了之后过了）

            3. 波形发生部分我们方波、锯齿等，跳变点总是会变成一段弧，改成用查表法也没用。结论是358的问题，用示波器看358前一级DA的输出边缘性是很好的，yyw说改不好放到实验报告分析去

            4. 波形发生还有一个问题是我们纹波很大且去不掉，方波上尤其明显，最后yyw也是让实验报告里分析

            5. 幅度、频率的测量范围，波形记忆的最大时间，采样率这些应该是必问的，提前准备好

            6. 隔壁组用了11.052的晶振，yyw要求改代码把采样率变成2k（神了，怎么会有这种要求）


    - 实验二

        1. 测温，脉搏，心电三选一，难度方面测温略小于脉搏远小于心电，我选了测温，单纯混过去。实验都给出了电路图，原理是没问题的，但是电阻的需要调整过，不要按他的。

        2. 之前很多帖子都有提到实验室的万用表温度计不准，但这个其实没关系。验收的时候只要你的示数和温度计的示数能对应就行。也就是说，他给的那个测温电阻的查表，或者电阻温度换算理论公式都没有用。而你只要完成测量点电压-温度的映射拟合就行了，如果一直纠结于用他的计算公式算温度，误差会很大。我们一开始也是执着那个换算公式，导致一直调不准确，放弃之后直接对测量电压进行拟合就好了。

        3. 由于各种原因一直没做出来，浪费一些时间，我们最后的测量电路也很简单，虽然原理图是按照要求画的，但是验收只焊接了一部分器件，简单说就是二极管稳压后直接由温度电阻和定值电阻分压，测量中间点的电位，其他什么LM358的比较器，电压跟随全都扔掉，回归最原始，然后根据这个分压值拟合到温度，反正最后验收还是比较准确

        4. 验收还有一个要求是记录10min的热水降温曲线，这个本质上就是考察一个数据存储功能，并不是验收时真的要显示出10min的曲线。我们是先把最大存储时间缩到40s还是60s（本质就是改一个ram的最大使用空间的事，你把最大地址设成8000当作10min，那相当于8K空间全用了，你临时设成800那就只存1min的长度），然后在这期间反复的把探头放在热水和冷水里切换，最后出来就是一个反复上升下降的波形，能看到这个波形就能证明你是有存储功能的，就过了。

        5. 实验二尽量早开始，一般春七周大部分实验一就验收完了，建议马上开始画实验二的pcb，投板就要一周时间，然后写代码。等到夏二夏三器件到齐之后赶紧焊板子，调代码，快的话夏五就能验收了。不要拖到很晚

        6. 他给的电路图LM358都是没接负电源的，这不好，自己画的时候要把负电源画上。

- 其他

    1. yyw在第一节课就说了会代码和报告查重，虽然不知道最终有没有这么做，但是务必不要直接把祖传/别的组的成功代码直接交上去，用你的ai改改，很简单的事，而且上面也说了，代码归代码，验收归验收，交上去报告里的代码不等于实际验收时烧录的代码。
    
    2. 电设这门课最重要的就是坚持，相信一切都会过去，总能验收过的，不要给自己太大压力
