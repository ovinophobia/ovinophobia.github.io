## 课程总结与建议

这个课没有任何改变。上课还是对着英文教材的pdf干讲，然后会讲一部分关于时序的知识，教材上没有。在开学的时候我尝试听了三四节课，但后来实在是坚持不下去了。考试的复习就直接看祖传的syh学长的ppt，基本完全涵盖了考试的内容，把里面的学会考卷里理论的部分就没什么问题了。

实验依旧是那七个实验，由于现在的ai对于时序的理解还是不行，虽然实验很简单，但直接让ai写verilog基本还是有点问题。此外，实验要求的叙述文字比较简单，所以大家最后的波形可能会有不同，但在功能上满足要求，具体的表现就是版搜找到的祖传代码不仅写法、思路完全不同，最终的波形也可能不一样。

因为考试有设计和编程题，我个人觉得对于实验比较好的处理方法是让ai帮你分析，比如状态机设置哪几个状态，分别什么用，又比如握手信号怎么设计。然后自己具体去写实现，写完再让ai检查再改。我是这么干的，然后考前也没有专门复习编程题，考试时候的感觉还可以，虽然写不完，但都是有大概思路的，不会出现一脸懵的情况。
