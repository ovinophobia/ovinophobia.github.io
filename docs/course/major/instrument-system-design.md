# 仪器系统设计

- **任课教师：** 周泓
- **学分：** 2.0
- **课程类别：** 专业课程必修
- **学期：** 2025-2026春夏

## 课程总结与建议

这门课今年也改了，终于是脱离了老古董树莓派。今年的实验是要做一个ESP32的智能手环，可以读取心电、脉搏数据并显示。硬件全部已经做完，要做的只是固件的开发，和算法的编写。课程组的设想是“用AI完成一个项目的开发”，课程提供了GLM、deepseek、mimo的api，每天有用量限制但是实测除非你把所有任务积压在ddl的一天之内完成，否则是很充裕的，不用担心用完的问题，当然想用自己的api也不会限制。根据短学期马老师的叙述，这个课的api好像全是周老师组自费的（误闯天家了，这就是豪华大组吗，经费充足这一块）

然后助教录制了完整的视频，以及相关的实验手册，文档，很丰富，绝大部分的问题都能比好的解决了。整个项目就是各种拷打ai干活，记得如果一个功能一直跑不对的话及时尝试换一个模型审阅。最后会有实物验收，以及开课时会使用ZJUGit给大家分组，会检查每个人对项目的贡献（直观的就是看提交情况），整个开发过程除了会检查Git上的项目文件，还需要有Devlog，最终还要有Report，其实也就是多拷打几次ai的事，不过养成一边开发一遍写文档记录的习惯还是很好的。虽然中间有各种各样的问题，但整体的体验还是不错的，至少对于我这种普通同学、平常也没有项目经验的来说是真学到有用的东西了。

考试的话只能说被称为周概也是有原因的，把ppt完整浏览一遍，然后复习课讲过的内容重点记一下应该问题也不大了，记得多写一点，复习资料的话我看的主要是历年卷和落浥老师的资料，版搜都有。
