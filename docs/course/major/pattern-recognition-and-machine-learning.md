## 课程总结与建议

新课，今年是开课的第二年，版搜有很多报告和资料。整体就是介绍各种传统的机器学习方法，因为我之前是没接触过相关内容的，算是有点收获吧。
包含四个报告80分，会有签到和上课表现10分，最后一节课小测占10分。

今年吐槽最多的是这个上课表现大家都扣分了，但是也没说这个怎么样才算是有互动，整体是老师管老师讲，和同学的交流还是少了一点。

实验报告的话要求latex，写作语言不限，但会有要求特定模板，但是这个模板是英文期刊的，这就导致在引入模板后再引入中文包部分数学符号会显示错误，所以一些数学公式我不得不用图片的方式放上去。而且这个模板下图片的排布也很奇怪，我使用的时候所有图片都会堆在文末而不是正文中它该出现的地方。不太理解。

内容方面把老师要求的都做了应该拿个80+还是容易的，但要是想拿90+就真的需要很详尽的分析，还需要你真的对实验有些想法或者说是巧思。个人体验是实验设计大于实验内容，如果能想到一些实验要求之外的设计进行研究应该是加大分的，但是这种“巧思”和创造就不是你主观上想做就能做到的了。

以及，每个实验都很费时间，我基本上一天调代码，一天写报告，中间还有很多零碎的时间也在做。

实验报告中图片插入的方法：用的overleaf，左上角设置把编译器改成XeLaTeX，代码如下：

!!! note "代码"
    ```latex
    \begin{center}
        % 修改 0.7 可以调整图片大小
        \begin{minipage}{0.7\columnwidth}
            \centering
            % 替换为实际图片文件名
            \includegraphics[width=\textwidth]{output2.png}
            \vspace{0.5em}
            \stepcounter{figure}
            \label{fig:ground_truth}
            % 在这里修改图名
            \noindent\textbf{Figure~\arabic{figure}:}
            \small{实验一迷宫设计图}
        \end{minipage}
    \end{center}
    ```
